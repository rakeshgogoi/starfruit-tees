# Product images

Current images in use:

**Maya (Black variant):** `maya-shirt-black.png`, `maya-shirt-black-splash.png`  
**Maya (White variant):** `maya-shirt-white.png`, `maya-shirt-white-splash.png`

Other products: add images to `public/products/` and reference them in the admin or `public/products.json`.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

To change which images a product uses, edit the product in the admin panel or in `public/products.json`.
